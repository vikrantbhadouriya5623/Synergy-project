System Objective

The primary objective of this project is to automate colour-based object sorting using sensors, Arduino/ESP32 control and a conveyor-based sorting mechanism. The system demonstrates end-to-end integration of sensor hardware data acquisition with robust Object-Oriented Programming (OOP) principles in Java, ensuring modularity, type safety, testability, and graceful fault recovery during academic evaluation.

verified Key OOP Concepts Demonstrated for Viva Examiners

1. Encapsulation Private sensor calibration offsets accessed strictly via validated getters and setters in SortingResult and Machine.
2. Inheritance ColourSensor extends common abstract Sensor class to inherit sampling infrastructure and avoid code duplication.
3. Polymorphism Common readRaw() method overridden across sensor types and dynamically invoked in asynchronous polling loops.
4. Separation of Concerns Decoupled UI telemetry, microcontroller serial bridges, and sorting logic via dedicated MVC layers.
